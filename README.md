# Todo List with Calendar

A modern, responsive to-do list application with calendar integration built with HTML, CSS, and JavaScript.

## Features

### Calendar Integration
- Interactive monthly calendar view
- Navigate between months with arrow buttons
- Visual indicators for dates with tasks (green dots)
- Today's date is highlighted in orange
- Selected date is highlighted in blue
- Click any date to view/edit tasks for that day

### Task Management
- Add new tasks for any selected date
- Mark tasks as complete/incomplete with checkboxes
- Edit existing tasks
- Delete tasks
- Tasks are automatically saved to local storage
- Visual feedback for completed tasks (strikethrough and grayed out)


## Features to Use

1. **Navigate the Calendar**: 
   - Use the arrow buttons to change months
   - Click on any date to select it
   - Dates with tasks show a green dot indicator
2. **Add Tasks**:
   - Select a date on the calendar
   - Click "Add Task" button
   - Enter your task description
   - Press Enter or click "Save"
3. **Manage Tasks**:
   - Check/uncheck the checkbox to mark tasks complete
   - Click the edit icon to modify a task
   - Click the trash icon to delete a task
4. **View Tasks**: Tasks for the selected date appear in the right panel

## Browser Compatibility

This application works in all modern browsers that support:
- ES6 Classes
- Local Storage API
- CSS Grid and Flexbox
- CSS Custom Properties

## Technologies Used

- **HTML5**: Semantic structure
- **CSS3**: Modern styling with Grid, Flexbox, and animations
- **JavaScript (ES6+)**: Object-oriented programming with classes
- **Font Awesome**: Icons for better UX
- **Local Storage**: Data persistence
